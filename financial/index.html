Privacy-focused first version

No bank passwords or live bank connections

Fennington Financial works from CSV files you choose to upload. The first version does not request banking credentials, initiate transfers, pay bills, or connect directly to financial institutions.

Financial records are scoped to the authenticated user in Firestore. Demo mode uses fictional data only and is clearly labeled.

First-draft boundary

This build avoids claims about encryption certifications, regulatory compliance, credit monitoring, investments, automated decisions, or adviser recommendations.
