# Fennington Solutions

Professional web design and development portfolio site.

## Features

- Modern, responsive design
- Service showcase
- Portfolio section for sample projects
- Contact information
- Mobile-first approach
- Fast loading, static HTML

## Deployment

This site is designed to be deployed on:
- Cloudflare Pages
- GitHub Pages
- Netlify
- Any static hosting provider

## Local Development

Simply open `index.html` in your browser or use a local server:

```bash
# Python
python -m http.server 8000

# Node.js (npx)
npx serve
```
