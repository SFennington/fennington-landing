# Daily Walkthrough Inventory

Purpose: capture every repeated homestead task before building your planner.

## How to use
1. Walk through the property at the same time you normally do chores.
2. Write each repeated task as you see it.
3. Mark timing, area, owner, backup, and supplies.
4. Transfer confirmed tasks into your daily checklist or weekly planner.

## Sorting Prompts

- Which tasks happen every morning?
- Which tasks happen every evening?
- Which tasks are weekly or seasonal?
- Which tasks are easy to forget?
- Which tasks need a backup person?
- Which tasks require supplies that run out?
