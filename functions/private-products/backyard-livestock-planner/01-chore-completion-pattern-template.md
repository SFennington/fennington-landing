# Chore Completion Pattern Template

Purpose: track completions, spot skipped tasks, and notice where routines are causing burnout.

Use a checkmark, initials, or a short note in each day column.

## Pattern Review

- Which task was skipped most often?
- Was the missed task assigned to the wrong time of day?
- Did the task need supplies, weather, or another person?
- Can it be batched with another chore?
- Can the task be simplified, delegated, or removed?

## Burnout Warning Signs

| Warning Sign | Evidence | Fix To Try |
| --- | --- | --- |
| Task skipped 3+ times | | Change owner or timing |
| Task always delayed | | Move to another routine block |
| Task needs too many steps | | Break into smaller checklist |
| Task depends on missing supplies | | Add to supply tracker |
